# Iniciar una conversación nueva

Estos textos permiten trabajar en conversaciones separadas sin volver a reconstruir todo el contexto. Adjuntar o abrir el repositorio `Congelados-Romasil` antes de usarlos.

## Conversación dedicada a la web

```text
Trabajaremos solamente en la web de Congelados Romasil. Lee primero README.md, AGENTS.md y docs/WEB.md. GitHub es la fuente de verdad y Netlify y Vercel despliegan desde la rama main. Acumula los cambios localmente y no crees commits ni publiques hasta que yo lo autorice expresamente. No cambies la configuración de correo salvo que te lo pida.
```

## Conversación dedicada al correo

```text
Trabajaremos solamente en el correo de Congelados Romasil. Lee primero README.md y docs/CORREO.md. Cloudflare Email Routing recibe y reenvía; Gmail contiene los buzones finales; Resend se reserva para envío programático. No modifiques la web ni publiques código salvo que te lo pida. No muestres ni guardes claves API, contraseñas o códigos de verificación en el repositorio.
```

## Conversación para publicar un lote web

```text
Revisa README.md, AGENTS.md y docs/WEB.md. Muéstrame todos los cambios locales pendientes y las pruebas realizadas. No publiques todavía. Después de mi autorización expresa, crea un único commit, súbelo a main y verifica los despliegues de Netlify y Vercel.
```

## Cómo cerrar una conversación

Antes de terminar una sesión de trabajo, pedir:

```text
Actualiza la documentación del área con el estado final, decisiones tomadas, cambios pendientes y pruebas realizadas. No incluyas secretos. Si son cambios web, déjalos locales hasta que autorice publicar el lote.
```
